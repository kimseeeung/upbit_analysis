# 01. 기능 명세

기준일: 2026-11-13. 이 문서가 기능과 규칙의 정답입니다.

## 0. 사용자 유형

| 유형 | 설명 |
| --- | --- |
| 트레이너 | 수강생 일정·이용권·규칙 관리. 센터 한 곳에 소속되거나 개인으로 활동 |
| 수강생 | 담당 트레이너는 한 번에 한 명. 트레이너가 바뀌어도 계정·이용권·이력은 이어짐 |
| 센터 관리자 | 소속 트레이너 전체를 조회. 수업을 하지 않는 관리자용 회원 유형 |
| 트레이너 + 센터 권한 | 트레이너 계정에서 "센터 만들기"를 하면 센터 관리자 권한이 더해짐. 상단 메뉴에서 화면 전환 |
| 운영 관리자 | 서비스 운영, 버전 롤백. 별도 주소(/admin)와 별도 계정 |
| 미가입 수강생 | 트레이너가 이름·전화번호로 임시 등록한 수강생. 카톡 링크로 일부 응답 가능 |

### 1.2 전화번호 본인인증

1. 전화번호 입력 → "인증번호 받기"
2. SMS로 6자리 발송, 3분 유효
3. 일치하면 "인증 완료". 인증이 끝나야 가입 버튼 활성화

- 재발송은 30초 뒤부터, 하루 5회까지. 5회 틀리면 새 번호를 받아야 함
- 같은 인증 화면을 아이디 찾기, 비밀번호 재설정, PIN 재설정, 전화번호 변경, 탈퇴, 운영 관리자 2단계 인증에 재사용

- 테스트 모드(문자 발송 대행사 연결 전): 실제 문자를 보내지 않는 개발 설정(`SMS_PROVIDER=console`)에서는 인증번호가 **000000**으로 고정되고 화면에 미리 채워짐. 재발송 대기·하루 5회 제한도 두지 않음. 운영 관리자 2단계 인증에는 쓰지 않음. 대행사를 연결하면 자동으로 꺼짐

### 1.3 약관 및 수신 동의

가입 마지막 단계. "전체 동의" + 항목별 "보기".

| 항목 | 구분 | 내용 |
| --- | --- | --- |
| 서비스 이용약관 | 필수 | |
| 개인정보 수집·이용 | 필수 | 수집 항목, 목적, 보관 기간(탈퇴 후 5일) |
| 개인정보 제3자 제공 | 필수 | 연결된 트레이너·수강생, 소속 센터에 이름·전화번호·수업 기록 제공 |
| 개인정보 처리 위탁 | 고지 | SMS 인증번호 발송 대행사, 서버 운영사 |
| 수업 알림 수신 (웹 푸시·카카오톡) | 필수 | 서비스 이용에 꼭 필요한 알림 |

- 동의 항목, 약관 버전, 동의 일시 저장. 선택 항목은 내 정보에서 변경
- 약관 변경 시 시행 7일 전 공지, 다음 로그인 때 재동의 화면
- 마케팅 수신자에게 2년마다 동의 사실 안내, 21:00~08:00 광고성 메시지 금지
- 약관·개인정보 처리방침 전문은 법률 검토 후 확정

### 1.4 가입 후 처리

- 트레이너가 먼저 임시 등록한 수강생과 전화번호가 같으면 "이 트레이너의 수강생이 맞나요?" 확인 후 기존 기록을 합침
- 가입 직후: 알림 허용·홈 화면 추가 안내 화면(Android·iPhone 별도)
- 트레이너는 이어서 근무 가능 시간 첫 설정 화면("나중에 하기" 가능)

## 2. 로그인 및 계정

### 2.1 로그인

- 회원 유형(트레이너 / 수강생 / 센터 관리자) 선택 → 아이디·비밀번호
- 비밀번호 마스킹 + 보기 토글
- 오류 문구는 "아이디 또는 비밀번호가 맞지 않습니다"로 통일
- 5회 연속 실패 시 10분 잠금
- 아이디 저장, 자동 로그인

### 2.2 자동 로그인

- 체크하면 서버가 발급한 토큰만 기기에 저장 (비밀번호 저장 금지)
- 30일 유지, 접속할 때마다 30일로 연장
- 해제: 로그아웃, 비밀번호 변경·재설정, 30일 미접속, 로그인 기기 목록에서 해당 기기 로그아웃
- 내 정보 > 로그인된 기기 목록(기기 종류, 마지막 접속), "모든 기기에서 로그아웃"
- 자동 로그인이어도 완료 승인은 PIN, 비밀번호 변경·탈퇴는 비밀번호 재입력
- "공용 기기에서는 사용하지 마세요" 안내

### 2.3 계정 관리

- **아이디 찾기**: 유형·이름·전화번호 → 본인인증 → 아이디 일부 마스킹(kim***) + 가입일. "전체 아이디 문자로 받기"
- **비밀번호 재설정**: 아이디·전화번호 → 본인인증 → 새 비밀번호(직전 비밀번호 금지) → 다른 기기 모두 로그아웃
- **PIN 재설정**: 본인인증 후 새 PIN
- **내 정보 수정**: 이름, 근무지. 전화번호 변경 시 새 번호로 본인인증
- **로그아웃**
- **회원 탈퇴**: 2.4

### 2.4 회원 탈퇴

1. 내 정보 > 회원 탈퇴
2. 안내: 삭제되는 정보, 탈퇴 후 같은 아이디로 재가입 불가
3. 남은 이용권·예정 수업이 있으면 경고 (트레이너는 연결 수강생 수·예정 수업 수)
4. 비밀번호 재입력 또는 본인인증, 탈퇴 사유(선택)
5. 완료 안내창:
   > 탈퇴 신청일로부터 5일 동안 개인정보와 기록이 유지된 뒤 삭제됩니다. 삭제 예정일: ○월 ○일. 5일 안에 다시 로그인하면 탈퇴를 취소할 수 있습니다. 탈퇴를 취소해도 취소된 예약은 복구되지 않습니다.

- 신청 즉시: 계정 정지 상태, 예정 예약 차감 없이 취소, 연결된 상대방에게 "탈퇴 예정" 알림
- 5일 안에 로그인 → "탈퇴를 취소할까요?" 화면
- 삭제 하루 전 "내일 계정이 삭제됩니다" 알림
- 5일 후 자동 삭제
  - 수강생 탈퇴: 개인정보와 본인 기록(예약, 승인 이력, 메모, 이용권) 삭제. 트레이너 화면에는 이름 없는 "탈퇴 회원"으로 수업 횟수만 남음
  - 트레이너 탈퇴: 개인정보만 삭제. 수강생 이력의 수업은 유지하고 트레이너 이름을 "탈퇴 트레이너"로 표시. 수강생 처리는 7.4
  - 센터의 마지막 관리자: 9.5
- 상대방 휴대폰의 오프라인 백업에서도 삭제되도록 동기화
- 5일 보관과 삭제 항목을 개인정보 처리방침에 명시

## 3. 수강생·이용권·수강 규칙 (트레이너)

### 3.1 수강생 등록과 연결

- 가입 수강생 불러오기: 이름 또는 전화번호 검색. 결과의 전화번호는 010-****-1234로 표시 → 수강생에게 연결 동의 요청
- 미가입 수강생 임시 등록: 이름 + 전화번호(필수). 가입하면 1.4대로 합침
- 수강생이 보낸 연결 요청은 요청함에서 승인·거절
- 목록: 이름 검색, 상태 필터(수강 중 / 만료 / 중단 / 담당 없음), "규칙 미동의" 표시
- 상세: 기본 정보, 이용권 이력, 수업 이력, 트레이너 메모, 알림 설정
- 수강 종료: 목록에서 숨기고 기록은 보관

### 3.2 PT 이용권

| 항목 | 입력 | 설명 |
| --- | --- | --- |
| 이용권명 | 필수 | 예: "PT 20회 (2026 겨울)" |
| 등록 횟수 | 필수 | |
| 서비스 횟수 | 선택 | |
| 시작일 / 만료일 | 필수 | 만료일 자동 제안(예: 20회는 3개월) |
| 1회 수업 시간 | 필수 | 기본 50분. 예약 길이와 신청 칸 길이의 기준 |
| 결제 금액 / 결제일 / 결제 수단 | 선택 | 앱은 결제 기록만 입력. 실제 결제는 받지 않음 |
| 수강 규칙 | 필수 | 트레이너 기본 규칙을 불러오고 수강생별로 수정 가능 |
| 메모 | 선택 | |
| 판매 트레이너 | 자동 | 등록한 트레이너 |
| 사용 / 잔여 횟수 | 자동 | 3.4 |
| 상태 | 자동 | 사용 중 / 일시정지 / 소진 / 만료 / 환불 / 사용 중지 |

등록 절차: 수강생 상세 > 이용권 추가 → 입력 → 저장하면 바로 "사용 중" → 수강생에게 이용권 내용과 규칙 동의 요청(3.5)

- 횟수·만료일을 바꾸면 변경 이력을 남기고 수강생에게 알림
- 만료일 연장, 서비스 횟수 추가, 환불 처리 버튼
- 이용권이 여러 개면 이전 이용권부터 사용

### 3.3 이용권 일시정지

- 트레이너가 설정하거나 수강생이 요청 → 상대방 승인 시 적용
- 시작일, 종료일, 사유(부상·여행·개인 사정 등)
- 정지 기간에는 예약 불가. 기간 안의 기존 예약은 차감 없이 취소
- 정지한 일수만큼 만료일 자동 연장. 일찍 재개하면 실제로 쉰 일수만 연장
- 한도는 수강 규칙에서 설정 (기본 1회 최대 30일, 이용권당 2회)
- 캘린더에 정지 기간을 빗금으로 표시. 시작·종료 하루 전 양쪽에 알림

### 3.4 잔여 횟수와 예약 가능 횟수

- 잔여 횟수 = (등록 횟수 + 서비스 횟수) − 완료 − 차감된 노쇼 − 차감된 당일 취소
- 예약 가능 횟수 = (수업 날짜에 유효한 이용권들의 잔여 합) − 예정 예약 수
- 예정 예약 = 확정 대기 + 예약 확정 + 변경 요청 중 + 신청 대기 + 완료 승인 대기
- 예약 가능 횟수가 0이면 새 예약, 반복 예약, 수강생 신청, 신청 수락 모두 불가 ("이용권 추가" 버튼 안내)
- 이용권 만료일 이후 날짜는 예약 불가. 일시정지 기간도 불가
- 반복 예약은 예약 가능 횟수만큼만 만들고 "n건은 잔여 부족으로 만들지 않았습니다" 안내
- 이미 잡힌 예약이 차감 등으로 잔여보다 많아지면:
  1. 넘는 만큼 가장 나중 예약을 "잔여 부족" 상태로 바꿈(진행 불가, 캘린더 회색 + 경고 아이콘)
  2. 트레이너와 수강생에게 즉시 알림: "잔여 횟수가 부족해 ○월 ○일 예약을 진행할 수 없습니다. 이용권을 추가하면 다시 확정됩니다."
  3. 이용권이 추가되면 원래 상태로 자동 복구
  4. 수업 24시간 전까지 해결되지 않으면 차감 없이 자동 취소. 이 상황이 수업 24시간 이내에 생겼으면 수업 2시간 전까지 기다린 뒤 취소

### 3.5 수강 규칙과 동의

트레이너가 정하고(센터 기본 규칙이 있으면 초기값), 수강생이 동의합니다.

| 규칙 | 선택지 | 기본값 |
| --- | --- | --- |
| 당일 취소 | 기준 시간 6 / 12 / 24 / 48시간 전, 기준 이후 취소 시 1회 차감 / 차감 안 함 | 24시간, 1회 차감 |
| 노쇼 | 판정 시간 수업 시작 후 10 / 15 / 30분, 1회 차감 / 차감 안 함 | 15분, 1회 차감 |
| 지각 | 15분 이내 지각은 남은 시간만 수업 | - |
| 미승인 | 완료 승인 요청 후 N일 응답 없으면 완료 처리 | 7일 |
| 예약 변경 기한 | 수업 N시간 전까지 변경 요청 가능 | 24시간 |
| 일시정지 한도 | 1회 최대 일수, 이용권당 횟수 | 30일, 2회 |

동의 절차:
1. 트레이너가 설정 > 수강 규칙에서 기본 규칙 설정
2. 이용권 등록 때 또는 수강생 상세의 "규칙 동의 요청 보내기"
3. 수강생은 앱 요청함 또는 카톡 공유 링크에서 규칙 전문 확인 → "동의" 또는 "문의하기"
4. 동의 일시와 규칙 내용(버전)을 이용권에 저장, 트레이너에게 결과 알림

- 24시간 무응답 시 리마인드. 목록에 "규칙 미동의" 표시
- 동의하지 않아도 예약은 가능. 예약 등록 시 "수강 규칙에 동의하지 않은 수강생입니다" 경고
- 동의 전에는:
  - 노쇼·당일 취소는 기록만 하고 차감하지 않음("미동의로 차감 안 함" 표시)
  - 미승인 자동 완료를 하지 않음. 기한이 지나면 트레이너에게 알리고 트레이너가 직접 완료 처리("트레이너 확정")
- 규칙을 바꾸면 다시 동의 요청. 동의 전까지 이전 규칙 적용
- 차감 알림에는 적용한 규칙을 함께 표시

### 3.6 수강생별 알림 설정

| 설정 | 기본값 | 내용 |
| --- | --- | --- |
| 전일 알림 | 보내기 | 수업 전날 트레이너가 정한 시각(기본 20:00, 08:00~21:00 사이만 선택) |
| 2시간 전 알림 | 보내기 | 수업 2시간 전 단순 안내 |

- 목록·상세에 각각 스위치. 여러 명 일괄 변경. 예약 하나만 예외로 끄기 가능

## 4. 예약과 캘린더

### 4.1 예약 상태와 전이

| 상태 | 의미 | 가능한 다음 상태 |
| --- | --- | --- |
| 신청 대기 | 수강생이 신청, 트레이너 응답 전 | 예약 확정(수락), 거절됨, 만료 |
| 확정 대기 | 트레이너가 등록, 수강생 응답 전 | 예약 확정(수락·자동 확정), 거절됨, 취소 |
| 예약 확정 | 확정됨. 하위 플래그: 자동 확정, 변경 요청 중, 취소 요청 중 | 완료 승인 대기, 노쇼, 취소, 잔여 부족 |
| 잔여 부족 | 3.4의 초과 예약 | 예약 확정(복구), 취소 |
| 완료 승인 대기 | 수업 종료 후 승인 요청됨 | 완료, 노쇼(종료 후 24시간 안), 취소(종료 후 24시간 안), 이견 처리 |
| 완료 | 승인됨, 1회 차감 | (트레이너 단독으로 되돌릴 수 없음) |
| 노쇼 | 트레이너 지정 | 이견 처리 결과에 따라 취소 |
| 취소 / 거절됨 / 만료 | 종료 상태 | - |

- 승인 방법 기록: 현장 PIN / 앱 PIN / 자동 완료 / 트레이너 확정 / 이견 처리
- 같은 시간 중복: 1:1 수업만 지원하므로 트레이너 등록, 수강생 신청, 변경 요청 모두 겹치는 시간에는 불가

### 4.2 캘린더 (트레이너)

- 월 / 주 / 일 보기, 년·월 이동, "오늘", 수강생 이름 필터, "오늘 미확인" 필터
- 상태별 색상: 확정 대기 / 신청 대기 / 예약 확정 / 완료 승인 대기 / 완료 / 노쇼 / 취소 / 잔여 부족
- 근무 가능 시간 밖은 회색. 일시정지 기간은 빗금
- 예약 칸 아이콘: 전일 알림 상태(4.8), "직접 보내야 함"(8.4), 규칙 미동의
- 예약 상세 팝업: 수정, 삭제, 취소, 노쇼 처리, 변경 요청, 카톡으로 보내기, 알림 예외 끄기, 발송·확인 시각, 다시 보내기

### 4.3 근무 가능 시간 (필수)

- 요일별 시간대 + 휴무일·예외일
- 수강생 신청은 근무 시간 안에서만. 트레이너는 근무 시간 밖에도 경고 후 직접 등록 가능
- 미설정이면 수강생 화면에서 예약 신청 버튼을 숨기고 트레이너에게 설정 안내

### 4.4 트레이너의 예약 등록

1. 빈 시간 클릭 → 수강생 선택(목록 / 검색 / 임시 등록), 시작 시각, 수업 시간, 메모, 반복(예: 매주 월·수 19시 8회)
   - 시작 시각: 년 / 월 / 일 / 오전·오후 / 시 / 분 드롭다운으로 선택 (분은 10분 단위)
   - 수업 시간: 10분 단위로 10~120분 중 선택, 기본값 50분
2. 검사: 예약 가능 횟수(3.4), 만료일, 일시정지, 중복, 근무 시간, 규칙 미동의, 늦은 시간(확정 요청이 수업 전에 닿지 않는 경우) 경고
3. 저장 → "확정 대기" + 수강생에게 확정 요청(웹 푸시, 알림 못 받는 수강생은 8.4)
4. 수강생: 수락 / 거절(사유) / 다른 시간 제안(1~3개, 트레이너가 하나 고르면 확정)
5. 수업 12시간 전까지 무응답이면 리마인드, 트레이너에게 "미확정" 표시
6. 수업 시작까지 무응답이면 자동 확정("자동 확정" 표시)

- 반복 예약은 묶어서 한 번에 수락·거절
- 미가입 수강생도 카톡 링크에서 가입 없이 수락·거절 (1회용 링크, 수업 시작까지 유효)
- 확정 대기 예약을 드래그하면 그대로 수정되고 확정 요청을 다시 보냄

### 4.5 수강생의 예약 신청

1. 수강생 캘린더에 트레이너의 빈 시간("예약 가능")만 표시. 다른 수강생 정보는 보이지 않음
2. 칸 길이는 이용권의 1회 수업 시간. 수업 12시간 전까지만 신청 가능
3. 동시 대기 신청은 3건까지. 예약 가능 횟수 검사
4. 트레이너가 요청함에서 수락하면 바로 "예약 확정" (수락 시점에 예약 가능 횟수 재확인, 0이면 수락 불가)
5. 거절하면 사유와 함께 알림. 수업 12시간 전까지 무응답이면 만료
6. 수업 24시간 전까지 응답 안 한 신청은 트레이너에게 리마인드

### 4.6 예약 시간 변경 요청

- 트레이너·수강생 모두 확정된 예약의 변경 요청 가능 (기한: 규칙의 예약 변경 기한)
- 트레이너가 확정된 예약을 드래그하면 바로 바뀌지 않고 변경 요청이 됨
- 수락할 때까지 원래 시간 유지. 캘린더에 "변경 요청 중", 새 시간은 점선
- 상대방: 수락 / 거절(원래 유지) / 다른 시간 제안
- 요청은 원래 시간과 새 시간 중 빠른 시각에 만료. 무응답이면 원래 시간대로 진행
- 완료된 수업은 이동 불가

### 4.7 취소

- 트레이너가 취소: 바로 취소, 차감 없음, 수강생에게 알림
- 수강생이 취소: "취소 요청" → 트레이너 수락 시 취소
  - 차감 여부는 요청한 시각 기준으로 규칙 적용 (늦게 수락돼도 불리하지 않음)
  - 수업 시작까지 트레이너 무응답이면 자동 취소(요청 시각 기준 규칙 적용)
  - 거절하면 예약 유지, 사유와 함께 알림
- 일시정지·탈퇴·잔여 부족으로 인한 취소는 차감 없음

### 4.8 수업 알림 확인 표시 (트레이너 캘린더)

| 아이콘 | 의미 |
| --- | --- |
| 회색 종 | 전일 알림 발송 예정 |
| 파란 종 | 보냈지만 미확인 |
| 초록 체크 | 수강생이 "확인했어요"(확정 대기 예약은 "수락") 누름 또는 알림을 눌러 앱을 엶 |
| 빨간 느낌표 | 보내지 못함(알림 미허용 등) |
| 빗금 종 | 이 수강생은 알림 꺼짐 |

- 전일 알림은 확인 여부만 기록·표시. 미확인이어도 재발송·트레이너 알림 없음
- 2시간 전 알림은 단순 안내. 확인 버튼·확인 기록 없음. 예약 상세에 발송 여부만 표시

## 5. 수업 완료 승인

### 5.1 흐름

1. 수업 종료 시각에 자동으로 "완료 승인 대기"로 바뀌고 수강생에게 승인 요청 발송
2. 트레이너는 종료 후 24시간 안에 노쇼·취소로 바꿀 수 있음(바꾸면 승인 요청 취소)
3. 승인 방법
   - 현장: 트레이너 기기에서 수강생이 PIN 입력
   - 앱: 수강생 요청함에서 PIN 입력
   - 카톡 링크: 회원은 PIN 입력. 미가입 수강생은 가입 화면으로 이동(이름·전화번호 미리 채움) → 가입·PIN 설정 후 바로 승인 화면
4. 승인 → "완료", 1회 차감, 트레이너에게 알림
5. 거절(사유 입력) → 5.2

- 승인 링크: 1회용, 48시간 유효. 24시간 미승인 시 리마인드(새 링크 발급)
- 규칙의 미승인 기한(기본 7일)이 지나면: 규칙에 동의한 수강생은 자동 완료, 미동의 수강생은 트레이너가 직접 완료 처리("트레이너 확정")
- PIN 5회 오류 시 잠금 → 본인인증 후 재설정
- 승인 기록: 일시, 방법, 요청한 트레이너
- 완료된 수업은 트레이너 혼자 되돌릴 수 없음

### 5.2 거절과 이의 제기

1. 수강생이 완료 승인을 거절하거나 노쇼에 이의 제기(사유 입력)
2. 트레이너가 요청함에서 선택: "수강생 의견 수락"(차감 취소 또는 상태 변경) / "기존 처리 유지"
3. 선택하면 종결, 수강생에게 결과 알림. 다시 요청할 수 없음
4. 트레이너가 7일 안에 선택하지 않으면 "수강생 의견 수락"

- 기록에 "이견 있음"과 양쪽 사유를 남기고 수강 현황 상세에 표시

## 7. 담당 트레이너 변경 · 퇴사 · 이동

### 7.1 원칙

- 수강생 계정, 이용권, 수강 이력은 그대로 이어지고 담당 트레이너만 바뀜
- 수업마다 진행한 트레이너를 저장. 수강생 이력에 수업별 트레이너 표시
- 이전 트레이너는 자기가 맡았던 수업만 조회(통계용). 이후 기록과 연락처는 볼 수 없음
- 결제 기록은 판매한 트레이너 이름으로 남음

### 7.2 변경 방법

| 시작 | 절차 |
| --- | --- |
| 수강생 | 내 정보 > 트레이너 변경 > 새 트레이너 선택 → 새 트레이너 수락 → 완료, 이전 트레이너에게 알림 |
| 이전 트레이너 | 수강생 상세 > 인계 > 트레이너 선택 → 새 트레이너 수락 → 수강생 동의 → 완료 |
| 센터 관리자 | 수강생 관리 > 담당 변경 → 새 트레이너 수락 → 수강생 동의 → 완료 |

넘어가는 것:
- 남은 이용권: 이전 트레이너의 "넘기기" 동의가 있어야 넘어감. 같은 센터 안이면 센터 관리자 승인으로도 가능(본인이 관련된 건은 스스로 승인 불가)
  - 동의하지 않으면 이용권은 이전 트레이너 쪽에 "사용 중지"로 남고, 새 트레이너는 새 이용권 등록. 정산은 앱 밖
  - 이전 트레이너 7일 무응답 시 수강생·새 트레이너에게 알리고, 센터 소속이면 센터 관리자에게 넘김
- 예정 예약: 새 트레이너가 수락할 때 예약별로 "유지" / "취소(차감 없음)"
- 수강 규칙: 새 트레이너 규칙 적용, 다시 동의 요청
- 트레이너 메모: 이전 트레이너가 넘길지 선택
- 알림 설정: 그대로 이어짐

### 7.3 센터 이동

1. 트레이너가 이동 신청(또는 센터가 소속 해제) → 담당 수강생 전원에게 선택 요청
2. 수강생 선택: "트레이너 따라가기" / "센터에 남기"(센터 관리자가 새 트레이너 지정)
3. 7일 무응답이면 "따라가기"
4. 이동은 선택 기한이 끝난 뒤 적용. 그 전 예약은 그대로 진행

- 센터 관리자는 진행 상황(따라감 / 남음 / 미응답) 확인
- 이전 센터는 이동 전 기간의 결제·수업 기록을 계속 조회. 따라간 수강생의 연락처는 가림

### 7.4 트레이너 탈퇴(퇴사)

- 수강생 선택: "센터가 정한 새 트레이너" / "직접 다른 트레이너 찾기"(연결 전까지 "담당 트레이너 없음", 이용권·이력 유지)
- 개인 트레이너는 "직접 찾기"만. 남은 이용권은 새 트레이너 연결 시 그대로 이어짐
- 선택 기한 5일(탈퇴 유예와 같음). 무응답: 센터 소속은 "센터가 정한 새 트레이너", 개인은 "담당 트레이너 없음"
- "따라가기"는 이동 때만 제공

### 8.3 야간 발송 제한 (2026-11-14부터 사용 안 함)

> 사용자 요청으로 발송·수신 시간 제한을 풀었습니다. 자동 알림은 시간과 관계없이 정한 시각에 바로 보내고, 전일 알림 시각은 00:00~23:30(30분 간격)에서 고릅니다. 아래 주석 문구도 표시하지 않습니다.
> 다시 켜야 하면 환경 변수 `NEXT_PUBLIC_NOTIFY_QUIET_HOURS=1`로 아래 규칙을 그대로 쓸 수 있습니다. 광고성(마케팅) 알림을 보내게 되면 정보통신망법에 따라 야간 수신 동의를 따로 받아야 합니다.

아래는 제한을 켰을 때의 규칙입니다.


- 21:00~08:00에는 자동 알림을 보내지 않고 08:00에 보냄
- 2시간 전 알림 시각이 야간이면 08:00에 보내되, 그 시각이 수업 1시간 전보다 늦으면 보내지 않음
- 트레이너가 야간에 "카톡으로 보내기"를 누르면 "지금은 야간 시간입니다. 그래도 보낼까요?" 확인창
- 알림 설정 화면, 트레이너의 수강생 알림 설정, "카톡으로 보내기" 버튼 아래에 이 문구를 표시:

> ※ 정보통신망법 제50조 제3항에 따라 오후 9시부터 다음 날 오전 8시까지는 별도 동의 없이 광고성 정보를 보낼 수 없습니다. 이 서비스는 수업 안내 알림도 같은 시간에는 보내지 않습니다.

### 8.4 알림 못 받는 수강생

- 트레이너 화면의 "알림 못 받는 수강생" 목록: 미가입, 알림 미허용, 발송 실패
- 전일 알림 시각에 트레이너에게 "카톡으로 보낼 수강생 n명" 알림 → 목록에서 카톡 공유로 한 명씩 발송
- 해당 예약에 "직접 보내야 함" 아이콘

### 8.5 트레이너 알림

- 트레이너는 알림 허용을 필수로 안내(신청·취소 요청은 응답이 없으면 만료·자동 취소되므로)
- 홈 화면에 대기 중인 요청 개수 배지

## 9. 센터

### 9.1 센터 가입과 권한

- 센터 관리자 유형으로 가입하거나 트레이너 계정에서 "센터 만들기"
- 한 센터에 관리자 여러 명 가능(기존 관리자가 초대)
- 트레이너는 센터 한 곳에만 소속. 옮기려면 기존 소속 해제 후 요청
- 센터 관리자 권한: 조회, 소속 관리, 담당 트레이너 변경, 남은 이용권 이동 승인(본인 관련 건 제외), 센터 기본 규칙, 관리자 추가, 센터 해산
- 예약 생성·수정과 수업 승인은 하지 않음

### 9.2 트레이너 소속

1. 센터가 초대 코드·링크를 보내거나, 트레이너가 센터를 검색해 소속 요청
2. 센터 관리자 승인
3. 트레이너가 "일정·수강생·이용권·결제 기록을 센터가 볼 수 있음"에 동의

### 9.3 센터 화면

| 화면 | 내용 |
| --- | --- |
| 센터 캘린더 | 소속 트레이너 전체 일정, 트레이너별 색상, 일 보기에서 트레이너별 열, 필터 |
| 트레이너 관리 | 목록, 소속 승인·거절, 초대, 해제, 이동 진행 상황 |
| 수강생 관리 | 센터 전체 수강생(담당 트레이너 표시), 담당 변경, 이용권 이동 승인 |
| 수강 현황 | 6장 표를 트레이너별 또는 센터 합계로. 트레이너별 수업 수·노쇼율 비교 |
| 결제 기록 | 기간별·트레이너별 합계, 엑셀 |
| 센터 설정 | 기본 수강 규칙(트레이너 초기값), 관리자 추가, 센터 해산 |

- 센터가 본 기록과 바꾼 내용은 이력으로 남김

### 9.4 센터 해산

- 소속 트레이너 전원에게 7일 전 알림 → 개인 트레이너로 전환. 수강생·이용권·기록 유지
- 센터의 결제 합계·통계 화면 삭제
- 센터장 겸 트레이너가 해산하면 센터 권한만 사라지고 트레이너 계정 유지

### 9.5 마지막 센터 관리자의 탈퇴

- 다른 관리자가 있으면 바로 탈퇴 가능
- 마지막 관리자는 "다른 관리자 지정" 또는 "센터 해산"을 먼저 해야 탈퇴 가능

## 11. 오프라인 백업과 복구

### 11.1 휴대폰 백업

- 브라우저 IndexedDB에 저장, 화면 파일은 Service Worker로 캐시
- 범위: 트레이너 — 내 수강생, 이용권, 규칙, 알림 설정, 예약(지난 3개월~앞으로 3개월) / 수강생 — 내 예약, 이용권, 이력 / 센터 관리자 — 1차 미지원
- 시점: 앱을 열 때, 열려 있는 동안 5분마다, 데이터가 바뀔 때마다 바뀐 부분만
- 저장 데이터 암호화, 로그아웃 시 삭제. 내 정보에 "마지막 백업" 시각
- 모바일 웹은 앱이 열려 있을 때만 백업 가능. iPhone은 오래 미접속 시 저장 데이터가 지워질 수 있어 홈 화면 추가 안내
- 서버 DB는 매일 자동 백업, 다른 장소에 30일 보관

### 11.2 오프라인 모드

- 서버 무응답·네트워크 끊김 감지 → 상단 주황 배너 "오프라인 · 마지막 동기화 11/13 20:10", 휴대폰 데이터로 표시
- 자동 로그인 상태여야 오프라인 화면을 열 수 있음

| 작업 | 오프라인 |
| --- | --- |
| 일정·이력·이용권 조회 | 가능(마지막 백업 기준) |
| 트레이너의 예약 등록·변경·취소, 노쇼 처리, 메모 | 휴대폰에 임시 저장, "동기화 대기" 표시 |
| 현장 완료 승인(PIN) | 임시 저장, 서버 복구 후 PIN 검증. 그 전까지 "승인 확인 중" |
| 수강생 예약 신청, 취소 요청 | 불가 |
| 알림·카톡 발송 | 불가, 복구 후 발송 |
| 회원가입, 새 로그인, 이용권·결제 기록 등록 | 불가(버튼 비활성화 + 이유 안내) |

### 11.3 복구 후 동기화

1. 배너 "동기화 중" → 임시 변경을 만든 순서대로 업로드
2. 서버 최신 데이터로 휴대폰 백업 갱신, 배너 닫힘
3. 미뤄 둔 알림 발송. 시각이 지난 수업 전 알림은 보내지 않음

- 충돌: 같은 예약을 다른 기기에서도 바꿨으면 서버 기록 유지, 휴대폰 변경은 "동기화 충돌" 화면에서 트레이너가 선택
- 시간 겹침은 서버에 먼저 들어온 예약 우선, 나중 것은 충돌 목록으로
- 서버 PIN 검증 실패 시 승인 취소 → 승인 요청으로 전환
- 임시 변경마다 기기·시각 기록

## 12. 운영 관리자

### 12.1 계정

- 별도 주소(/admin), 회원 유형 선택에 노출하지 않음
- 첫 관리자 계정은 배포 시 환경 변수로 생성. 아이디·비밀번호·롤백 PIN을 코드와 문서에 쓰지 않음
- 로그인: 비밀번호 + 등록된 휴대폰 인증(2단계). 5회 실패 30분 잠금. IP 제한 권장
- 자동 로그인 없음, 30분 미사용 시 로그아웃

### 12.2 관리자 관리

- 목록: 이름, 아이디, 추가한 사람, 추가일, 마지막 로그인
- 추가: 기존 관리자가 이름·휴대폰 번호로 초대 → 초대받은 사람이 아이디·비밀번호·롤백 PIN(6자리)을 직접 설정 → 휴대폰 인증 후 활성화
- 비활성화 가능. 최소 1명은 항상 활성
- 추가·비활성화 기록, 다른 관리자 전원에게 알림

### 12.3 버전 롤백

- 관리자 권한이 있는 사람은 모두 롤백 가능
- 배포 버전 목록: 버전, 배포 일시, 배포한 사람, 변경 요약, 현재 버전 강조
- "직전 버전으로 롤백" 또는 목록에서 버전 선택

1. 롤백 버튼 → 대상 버전과 변경 내용 확인
2. 본인 롤백 PIN 6자리 + 사유 입력
3. 이전 버전 재배포, 진행 상황 표시. 사용자에게 "잠시 점검 중"
4. 완료 후 주요 기능(로그인, 캘린더 조회) 자동 점검 결과 표시
5. 필요하면 "다시 최신 버전으로"

- 롤백 PIN 5회 오류 시 30분 잠금
- 기록: 실행한 관리자, 일시, 버전 → 버전, 사유, 점검 결과
- 롤백은 프로그램만 되돌리고 데이터는 그대로. DB 변경은 이전 버전과 호환되게 작성. 데이터 복구는 DB 백업 복원으로 별도 처리
- 새 버전은 테스트 서버에서 확인 후 배포

## 13. 공통·비기능

- 모바일 웹(PWA)으로 시작, 홈 화면 추가 시 앱처럼 실행. 네이티브 앱은 이후 검토
- 메인 화면 상단 "모바일 화면 / PC 화면" 전환. 처음엔 화면 너비로 자동 선택, 선택은 기기별 저장
  - 모바일: 하단 탭, 일·목록 보기 위주, 표는 카드형
  - PC: 왼쪽 메뉴, 주 보기 기본, 표 전체 열
- 캘린더 보기: 모든 캘린더(트레이너·수강생·센터)에서 일 / 주 / 월 / 목록 보기를 고를 수 있음. 날짜를 누르면 그날 일 보기
  - 트레이너 캘린더는 "수강생별 보기" 드롭다운으로 한 수강생(예: 이수강)의 일정만 볼 수 있음
- 날짜·시간 입력: 브라우저 달력 대신 드롭다운으로 선택
  - 날짜: 년 / 월 / 일(요일 함께 표시) — 이용권 시작·만료·결제일, 일시정지 기간, 수강 현황·결제 기간, 휴무·예외일, 생년월일 등 모든 날짜 칸
  - 시각: 오전·오후 / 시 / 분(10분 단위) — 예약 시작 시각, 변경 요청·다른 시간 제안, 근무 시간 등 모든 시각 칸
- 입력 키보드: 아이디·비밀번호처럼 영문 칸은 영문, 이름·메모처럼 글자 칸은 한글을 기본으로 안내
  - 웹에서는 휴대폰 키보드 언어를 강제로 바꿀 수 없으므로, 영문 칸에 한글 자판으로 친 글자는 같은 자리의 영문으로 자동 변환(예: "ㅅㄱ먀ㅜㄷㄱ1" → "trainer1")
- 디자인: 보라색 브랜드 색과 파스텔 아이콘으로 친근하고 귀여운 느낌. 둥근 카드, 메뉴·카드 제목·빈 화면 안내에 아이콘. 밝은/어두운 화면 모두 지원
- 화면 구성(모든 화면 공통): 위에서부터 ① 제목 영역(아이콘·제목·설명, 오른쪽에 주요 버튼) ② 조회 조건 영역(기간·검색·필터를 연보라 상자에 모음) ③ 요약 숫자(아이콘 카드) ④ 목록 영역(제목·건수 배지가 있는 카드). 영역마다 경계선·배경으로 구분
- 아이콘: 메뉴·제목·카드·버튼(수락·거절·저장·삭제·보내기·등록 등)·정보 항목(다음 수업·잔여·만료일 등)에 아이콘을 함께 표시
- 모든 통신 HTTPS. 목록·검색의 전화번호 마스킹
- 예약 생성·변경·삭제와 승인 이력은 누가·언제·무엇을 기록
- 모든 시각은 한국 시간 기준
- 1:1 수업만 지원. 그룹 PT는 후속 버전 후보
