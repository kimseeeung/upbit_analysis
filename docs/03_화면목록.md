## 공통 화면 구성·디자인 (13장)

| 요소 | 모바일 화면 | PC 화면 |
| --- | --- | --- |
| 상단 | 로고(덤벨 아이콘)·화면 전환·로그아웃 / 둘째 줄에 모바일·PC 전환과 내 이름 | 로고·화면 전환·모바일·PC 전환·내 이름·로그아웃 한 줄 |
| 메뉴 | 하단 탭(아이콘 + 이름) | 왼쪽 메뉴(아이콘 + 이름), 지금 화면 강조 |
| 캘린더 | 기본 일 보기, 일·주·월·목록 전환 | 기본 주 보기, 일·주·월·목록 전환 |
| 표 | 카드형 | 전체 열 |

- 색: 브랜드 보라(#7C5CFF), 파스텔 아이콘 배경(보라·분홍·노랑·초록·하늘)
- 카드: 둥근 모서리, 제목 앞 아이콘. 비어 있을 때는 아이콘과 함께 안내
- 입력: 날짜는 년/월/일, 시각은 오전·오후/시/분 드롭다운. 수업 시간은 10~120분(기본 50분)

### 화면 영역 구분 (모든 화면 공통)

1. **제목 영역**: 큰 아이콘 + 제목 + 한 줄 설명, 오른쪽에 그 화면의 주요 버튼(예약 등록, 엑셀 다운로드 등). 아래 경계선
2. **조회 조건 영역**: "조회 조건" 표시가 있는 연보라 상자 안에 기간·검색·상태 필터
3. **요약 영역**: 아이콘이 있는 숫자 카드(총 수업 수, 노쇼율, 결제 합계 등)
4. **목록 영역**: 제목과 건수 배지가 있는 카드 안에 표·목록. 비어 있으면 아이콘과 안내

### 버튼·아이콘 규칙

- 글자만 있는 링크는 쓰지 않고 아이콘 버튼으로: 로그인 화면 하단(아이디 찾기·비밀번호 재설정·회원가입)은 아이콘 타일 버튼 3개, 뒤로 가기는 ‹ 아이콘 알약 버튼
- 모바일 상단: 로그아웃은 아이콘만(눌러 보면 "로그아웃"), PC는 아이콘 + 글자
- 모바일 트레이너 캘린더: 예약 등록은 오른쪽 아래 떠 있는 + 버튼
- 불러오는 중: 스켈레톤
