# 02. 데이터 모델

Prisma 스키마로 옮기기 위한 초안입니다. 모든 테이블에 `id`(cuid), `createdAt`, `updatedAt`이 있다고 보고 생략합니다. 시각은 UTC로 저장하고 화면에서 Asia/Seoul로 변환합니다.

## 계정·인증

**User**
- loginId (unique), passwordHash, passwordSalt, passwordChangedAt
- role: TRAINER | STUDENT | CENTER_ADMIN
- name, phone (unique), phoneVerifiedAt, gender?, birthDate?
- status: ACTIVE | WITHDRAWING | DELETED
- withdrawRequestedAt?, deleteScheduledAt?
- loginFailCount, lockedUntil?
- displayMode: AUTO | MOBILE | PC (기기별은 클라이언트 저장, 이건 기본값)

**StudentProfile** (User 1:1, role=STUDENT)
- pinHash, pinSalt, pinFailCount, pinLockedUntil?

**TrainerProfile** (User 1:1, role=TRAINER)
- workplaceText? (센터 미가입 시 직접 입력)
- dayBeforeNotifyTime (기본 "20:00", 08:00~21:00)
- hasCenterAdmin (트레이너 + 센터 권한)

**Session** — tokenHash, userId, deviceLabel, lastSeenAt, expiresAt(30일 슬라이딩), revokedAt?

**SmsVerification** — phone, purpose(SIGNUP|FIND_ID|RESET_PW|RESET_PIN|CHANGE_PHONE|WITHDRAW|ADMIN_2FA), codeHash, expiresAt(3분), attempts, verifiedAt?

**TermsVersion** — kind(SERVICE|PRIVACY|THIRD_PARTY|NOTIFY|MARKETING), version, body, effectiveAt
**TermsConsent** — userId, termsVersionId, agreed, agreedAt

**PushSubscription** — userId, endpoint, p256dh, auth, userAgent, failedAt?

## 수강생과 연결

**Student** (사람 단위. 미가입 수강생도 여기)
- userId? (가입하면 연결)
- name, phone
- currentTrainerId? (null = 담당 트레이너 없음)

**TrainerStudentLink** (담당 이력. 현재 담당은 endedAt null 하나)
- trainerId, studentId, startedAt, endedAt?, endReason?
- memo (트레이너 메모), memoTransferred
- notifyDayBefore (기본 true), notify2h (기본 true)
- status: ACTIVE | ENDED | HIDDEN(수강 종료)

**LinkRequest** — 연결 요청. fromUserId, toUserId, studentId?, status(PENDING|ACCEPTED|REJECTED), respondedAt?

## 이용권·규칙

**Pass**
- studentId, soldByTrainerId, name
- count, bonusCount, startDate, endDate, sessionMinutes(기본 50)
- price?, paidAt?, payMethod?, memo?
- ruleSetVersionId
- status: ACTIVE | PAUSED | EXHAUSTED | EXPIRED | REFUNDED | SUSPENDED(이동 미동의로 사용 중지)
- usedCount, deductedNoShow, deductedLateCancel (캐시. 정답은 Booking에서 계산)

**PassChangeLog** — passId, field, before, after, changedBy, changedAt

**PassPause** — passId, requestedBy, startDate, endDate, reason, status(PENDING|APPROVED|REJECTED|ENDED_EARLY), actualEndDate?, approvedBy?

**RuleSet** (트레이너 또는 센터 소유, 바뀌면 새 버전)
- ownerTrainerId? / ownerCenterId?
- lateCancelHours (6|12|24|48, 기본 24), lateCancelDeduct (기본 true)
- noShowMinutes (10|15|30, 기본 15), noShowDeduct (기본 true)
- lateGraceMinutes (15)
- unapprovedAutoCompleteDays (기본 7)
- changeDeadlineHours (기본 24)
- pauseMaxDays (30), pauseMaxCount (2)
- version, createdAt

**RuleConsent** — passId, ruleSetVersionId, studentId, status(PENDING|AGREED|INQUIRED), requestedAt, agreedAt?

## 예약

**AvailabilityRule** — trainerId, weekday(0-6), startTime, endTime
**AvailabilityException** — trainerId, date, startTime?, endTime?, isOff

**Booking**
- studentId, trainerId(진행 트레이너, 기록용으로 고정), passId?
- startAt, endAt
- source: TRAINER | STUDENT
- status: REQUESTED(신청 대기) | PENDING_CONFIRM(확정 대기) | CONFIRMED | INSUFFICIENT(잔여 부족) | PENDING_APPROVAL(완료 승인 대기) | COMPLETED | NO_SHOW | CANCELED | REJECTED | EXPIRED
- autoConfirmed (bool), recurringGroupId?
- cancelRequestedAt?, cancelRequestedBy?, canceledBy?, cancelReason?
- deducted (bool), deductReason?: COMPLETED | NO_SHOW | LATE_CANCEL, deductSkippedReason?: NO_CONSENT
- approvedAt?, approvalMethod?: PIN_ONSITE | PIN_APP | AUTO | TRAINER_CONFIRM | DISPUTE_RESOLUTION
- disputed (bool), disputeStudentReason?, disputeTrainerDecision?: ACCEPT_STUDENT | KEEP
- notifyDayBeforeOff, notify2hOff (예약 단위 예외)
- offlineOrigin? (오프라인에서 만들어진 변경의 기기·시각)

**BookingChangeRequest** — bookingId, requestedBy, proposedSlots[] (1~3), status(PENDING|ACCEPTED|REJECTED|EXPIRED), expiresAt(원래·새 시간 중 빠른 시각), chosenSlot?

**BookingStatusLog** — bookingId, from, to, by(userId|SYSTEM), reason, at

## 알림

**Notification**
- userId?, studentId?(미가입 대상), bookingId?
- type (8.2의 각 알림), channel: WEB_PUSH | KAKAO_SHARE | SMS
- scheduledAt, sendAt(야간 보정 후), sentAt?, status: SCHEDULED | SENT | FAILED | SKIPPED | CANCELED
- confirmedAt? (전일 알림 "확인했어요"/수락, 알림 클릭)
- needsManualShare (bool, 알림 못 받는 수강생)

**ShareLink** — 1회용 링크. token(hash), purpose(CONFIRM_BOOKING|APPROVE|RULE_CONSENT|TRANSFER_CHOICE|LINK_REQUEST), refId, expiresAt, usedAt?

## 인계·센터

**TransferRequest** — studentId, fromTrainerId?, toTrainerId, initiatedBy(STUDENT|TRAINER|CENTER_ADMIN), toTrainerAcceptedAt?, studentAgreedAt?, passTransfer: PENDING | AGREED | REFUSED | CENTER_APPROVED | NOT_NEEDED, bookingDecisions(json: bookingId→KEEP|CANCEL), memoTransfer, status, deadlineAt

**Center** — name, address, phone, bizNo?, verified, status(ACTIVE|DISSOLVING|DISSOLVED), dissolveAt?
**CenterAdmin** — centerId, userId, invitedBy, addedAt
**CenterMembership** — centerId, trainerId, status(PENDING|ACTIVE|LEFT), consentAt?, joinedAt?, leftAt?  (트레이너당 ACTIVE 1개)
**TrainerDeparture** — trainerId, type(MOVE|WITHDRAW), targetCenterId?, deadlineAt(이동 7일, 탈퇴 5일), appliedAt?
**DepartureChoice** — departureId, studentId, choice(FOLLOW|STAY|CENTER_ASSIGN|FIND_OWN), chosenAt?, defaulted

## 운영

**OperatorAccount** — loginId, passwordHash/Salt, rollbackPinHash/Salt, name, phone, status(INVITED|ACTIVE|DISABLED), invitedBy?, lastLoginAt?, failCount, lockedUntil?, rollbackPinFailCount, rollbackLockedUntil?
**DeployVersion** — version, deployedAt, deployedBy, summary, isCurrent
**RollbackLog** — operatorId, fromVersion, toVersion, reason, startedAt, finishedAt?, healthCheck(json), result
**OperatorAccessLog** — operatorId, targetUserId, action, at
**Notice** — title, body, publishedAt
**Inquiry** — userId, title, body, answer?, answeredBy?, answeredAt?

## 공통

**AuditLog** — actorType(USER|OPERATOR|SYSTEM), actorId?, entity, entityId, action, before(json), after(json), at
**SyncConflict** — trainerId, entity, entityId, localChange(json), serverState(json), deviceLabel, createdAt, resolvedAt?, resolution

## 예약 작업 (pg-boss)

| 작업 | 시점 | 내용 |
| --- | --- | --- |
| send-notification | Notification.sendAt | 야간 보정된 시각에 발송 |
| auto-confirm | 수업 시작 | 확정 대기 → 확정(autoConfirmed) |
| expire-request | 신청 12시간 전 / 변경 요청 만료 | 신청 대기·변경 요청 만료 |
| auto-cancel-request | 수업 시작 | 무응답 취소 요청 → 취소(요청 시각 기준 규칙) |
| start-approval | 수업 종료 | 확정 → 완료 승인 대기 + 승인 요청 |
| approval-deadline | 승인 요청 + 규칙 일수 | 동의함: 자동 완료 / 미동의: 트레이너 확정 알림 |
| dispute-deadline | 이의 + 7일 | 수강생 의견 수락 |
| insufficient-deadline | 수업 24시간 전(또는 2시간 전) | 잔여 부족 예약 자동 취소 |
| pass-expire / pause-start/end | 해당 날짜 | 상태 변경, 알림 |
| departure-deadline | 이동 7일 / 탈퇴 5일 | 무응답 기본값 적용 |
| transfer-pass-deadline | 7일 | 이전 트레이너 무응답 처리 |
| delete-withdrawn | 탈퇴 + 5일 | 개인정보·기록 삭제, 상대방 백업 삭제 신호 |
| daily-db-backup | 매일 | 서버 DB 백업, 30일 보관 |
