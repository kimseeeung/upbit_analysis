# 04. 개발 순서

마일스톤 순서대로 개발합니다. 각 마일스톤은 완료 기준을 테스트로 확인한 뒤 다음으로 넘어갑니다.

## M0. 프로젝트 기반
- Next.js + TypeScript + Tailwind + Prisma + PostgreSQL, ESLint/Prettier, Vitest, Playwright
- 환경 변수 템플릿(`.env.example`): DB, VAPID, SMS, KAKAO_JS_KEY, 운영 관리자 초기 계정. 실제 값은 넣지 않음
- 시간 유틸(Asia/Seoul), 감사 로그 헬퍼, 권한 미들웨어 뼈대
- 완료 기준: 빈 화면 배포, `npm test` 통과

## M1. 회원가입·로그인 (명세 1, 2.1~2.3)
- 3가지 유형 가입, SMS 본인인증(어댑터 + 개발용 콘솔 출력), PIN, 약관 동의 기록
- PBKDF2 해시, 로그인 잠금, 자동 로그인 세션, 로그인 기기 목록
- 아이디 찾기, 비밀번호·PIN 재설정
- 완료 기준: 비밀번호·PIN 정책 단위 테스트, 5회 실패 잠금, 세션 30일 슬라이딩 테스트

## M2. 수강생·이용권·규칙 (명세 3.1, 3.2, 3.4, 3.5)
- 수강생 검색·연결 요청·임시 등록, 가입 시 전화번호로 합치기
- 이용권 등록·수정 이력, 여러 이용권 순서
- 규칙 세트(버전), 동의 요청, 미동의 표시
- `getAvailableCount()` 순수 함수 + 테스트
- 완료 기준: 잔여·예약 가능 횟수 계산 테스트(만료, 여러 이용권, 예정 예약 포함)

## M3. 예약과 캘린더 (명세 4)
- 근무 가능 시간, 트레이너 캘린더(FullCalendar), 예약 등록·반복·검사
- 상태 머신(4.1 표 외 전이 거부), 확정 요청·수락·제안·자동 확정
- 수강생 캘린더, 예약 신청·수락·만료, 변경 요청, 취소 요청
- 잔여 부족 보류·복구·자동 취소
- 완료 기준: 상태 전이 테스트 전체, 중복 시간 차단, Playwright로 등록→확정→변경 흐름

## M4. 수업 완료 승인 (명세 5)
- 종료 시 자동 승인 요청, 현장 PIN, 앱 PIN, 노쇼·취소 24시간 변경 창
- 거절·이의 제기 처리, 미승인 기한(동의/미동의 분기), 차감 판단 함수
- 완료 기준: 차감 판단 테스트(규칙 동의 여부, 요청 시각 기준 당일 취소)

## M5. 알림 (명세 8)
- 웹 푸시 구독·발송, pg-boss 작업, 야간 보정 함수 + 테스트
- 전일·2시간 전 알림, 수강생별·예약별 끄기, 확인 기록과 캘린더 아이콘
- 카카오톡 공유 버튼과 1회용 링크 화면들, 알림 못 받는 수강생 목록, 야간 확인창·주석 문구
- 완료 기준: 21:00~08:00 발송 0건, 08시대 수업 2시간 전 알림 생략 테스트

## M6. 수강 현황·일시정지 (명세 3.3, 6)
- 기간 통계(인계 귀속 규칙 포함), 수강생별 상세
- 일시정지 요청·승인·만료일 연장·조기 재개
- 완료 기준: 통계 귀속 테스트, 연장 일수 계산 테스트

## M7. 센터와 인계 (명세 7, 9)
- 센터 생성·관리자·소속, 센터 화면, 트레이너+센터 권한 전환
- 인계 3가지 경로, 이용권 넘기기 동의, 이동·탈퇴 선택과 기본값, 해산
- 완료 기준: 권한 테스트(센터는 소속 범위만, 본인 관련 승인 불가), 이동 후 이전 센터 조회 범위

## M8. 탈퇴·개인정보 (명세 2.4)
- 5일 유예, 탈퇴 취소, 삭제 작업(수강생/트레이너 다르게), 마지막 센터 관리자 처리
- 완료 기준: 삭제 후 상대방 화면 표시("탈퇴 회원"/"탈퇴 트레이너") 테스트

## M9. 오프라인 PWA (명세 11)
- 서비스 워커, IndexedDB 백업(암호화), 오프라인 배너, 임시 변경 큐, 동기화·충돌 화면
- 모바일/PC 화면 전환
- 완료 기준: 네트워크 차단 상태에서 조회·임시 저장 → 복구 후 반영

## M10. 운영 관리자 (명세 12)
- /admin 로그인(2단계), 관리자 초대·비활성화, 회원 조회 기록, 공지·문의
- 배포 버전 기록과 롤백(배포 플랫폼 API 연동은 어댑터로 분리), 점검, 롤백 기록
- 완료 기준: 롤백 PIN 잠금, 관리자 최소 1명 유지 테스트

## 배포 전 확인
- 약관·개인정보 처리방침 법률 검토
- SMS 발송 대행사, 카카오 개발자 앱(카카오톡 공유 도메인 등록), VAPID 키 발급
- 테스트 서버에서 전체 흐름 확인 후 운영 배포
