# 05. 결정 기록

기획 중 사용자가 결정한 사항과 이유입니다. 명세를 바꾸려면 여기에도 기록합니다.

| 영역 | 결정 | 이유·비고 |
| --- | --- | --- |
| 플랫폼 | 모바일 웹(PWA)으로 시작, 모바일/PC 화면 전환 | 네이티브 앱은 이후 |
| 비밀번호 | PBKDF2-HMAC-SHA256(솔트, 60만 회) | SHA-256 단독은 대입 공격에 약함 |
| 승인 비밀번호 | 별도 4자리 PIN, 수강생 가입 시 필수 | 로그인 비밀번호 노출 방지 |
| 전화번호 | 번호 하나에 계정 하나, 트레이너·수강생 겸용 불가 | |
| 수강생의 트레이너 | 한 번에 한 명. 바뀌어도 계정·이용권·이력 이어짐 | |
| 트레이너 소속 | 센터 한 곳만 | |
| 센터 관리자 | 조회 전용 + 소속·담당 변경·이용권 이동 승인 | 예약 수정 권한 없음 |
| 센터장 겸 트레이너 | 트레이너 계정에 센터 권한 추가 | 번호 하나에 계정 하나 규칙 때문 |
| 결제 | 결제 기록만 입력 | 앱에서 결제받지 않음 |
| 수강 현황 | 조회 기간 기준. 인계 시 수강·노쇼는 진행 트레이너, 전체·잔여는 현재 담당 | |
| 노쇼·당일 취소 | 트레이너별 설정, 수강생 동의 필요 | |
| 규칙 미동의 | 예약은 경고만. 노쇼·당일 취소 차감 안 함, 미승인 자동 완료 안 함(트레이너 확정) | 분쟁 방지 |
| 예약 확정 무응답 | 수업 시작 시 자동 확정 | 전일 알림에 수락 버튼으로 보완 |
| 예약 변경 | 양쪽 요청 가능, 수락 전 원래 시간 유지, 무응답 시 원래 시간 | |
| 수강생 취소 | 트레이너 수락 필요, 차감은 요청 시각 기준, 무응답 시 수업 시작에 자동 취소 | |
| 수강생 예약 신청 | 근무 가능 시간 안, 12시간 전까지, 대기 3건, 트레이너 수락 | |
| 잔여 0 | 예약 불가. 차감으로 생긴 초과분은 "잔여 부족" 보류 + 양쪽 알림 | |
| 완료 승인 요청 | 수업 종료 시 자동 | 트레이너가 잊는 문제 |
| 거절·이의 | 트레이너가 수락/유지로 종결, 7일 무응답 시 수강생 의견 수락 | 무한 반복 방지 |
| 미가입 수강생 승인 | 가입해야 가능 | 예약 확정 응답은 가입 없이 가능 |
| 이용권 일시정지 | 정지 일수만큼 만료일 연장 | |
| 트레이너 변경 시 이용권 | 이전 트레이너 동의 필요(같은 센터는 센터 관리자 승인 가능) | 선결제 횟수 보호 |
| 센터 이동 | 수강생이 따라가기/남기 선택, 7일 무응답 시 따라가기 | |
| 트레이너 탈퇴 | 센터가 정한 새 트레이너/직접 찾기, 5일, 수강생 이력 유지 | |
| 이전 센터 기록 | 이동 전 기간만 계속 조회, 따라간 수강생 연락처 가림 | |
| 마지막 센터 관리자 탈퇴 | 다른 관리자 지정 또는 해산 후 탈퇴 | |
| 알림 방법 | 자동은 웹 푸시, 응답 요청은 카카오톡 공유(무료), SMS는 인증만 | 카톡 자동 발송은 무료 불가 |
