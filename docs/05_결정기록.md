### M2 수강생·이용권·규칙

| 영역 | 가정 | 근거·비고 |
| --- | --- | --- |
| 예약 가능 횟수 계산 (3.4) | 예정 예약을 수업이 이른 순서로, 그 날짜에 유효한 이용권 중 "이전 이용권부터"(시작일 → 등록 순) 하나씩 배정. 예약 가능 횟수 = 그 날짜에 유효한 이용권들의 (잔여 − 배정된 예정 예약) 합 | "유효한 이용권 잔여 합 − 예정 예약 수"를 이용권이 여러 개일 때도 맞게 계산 |
| 잔여 부족 대상 | 어느 이용권에도 배정되지 못한 예정 예약. 이미 잔여 부족인 예약은 다른 예정 예약 뒤에 배정해, 자리가 생기면 복구 | 3.4 "가장 나중 예약", "이용권 추가 시 복구" |

| 환불·사용 중지 이용권 | 예약 가능 횟수에서 뺀다 | |
| 수강생 목록 상태 | 수강 중 = 오늘 쓸 수 있는 이용권(잔여 > 0) 있음 / 만료 = 없음(이용권 없음 포함) / 중단 = 수강 종료. "담당 없음"은 센터 화면(M7)에서 사용 | 트레이너 목록에는 담당 없는 수강생이 없음 |
| 규칙 미동의 표시 | 만료되지 않은 이용권 중 최신 규칙에 동의하지 않은 것이 있으면 | |

| 수강생별 규칙 | 기본 규칙과 다르게 고치면 이용권 전용 규칙(새 버전)을 만듦. 같으면 기본 규칙 버전을 그대로 씀 | |
| 기본 규칙 변경 | 이미 등록한 이용권에는 적용하지 않음(새로 등록하는 이용권부터) | 동의한 규칙을 몰래 바꾸지 않기 위해 |

| 수업 길이 | 그 날짜에 쓸 이용권의 1회 수업 시간(없으면 50분). 트레이너는 등록 때 10~240분으로 바꿀 수 있음 | |
| 반복 예약 | 최대 52회. 다른 수업과 겹치는 날짜도 건너뛰고 건수를 알려 줌 | |
| 늦은 시간 경고 | 지금이 야간(21~08시)이라 확정 요청이 08:00에 나가는데, 수업이 그보다 먼저 시작하면 경고 | 4.4 "확정 요청이 수업 전에 닿지 않는 경우" |
| 규칙 미동의 경고 | 한 번도 규칙에 동의하지 않은 사용 중 이용권이 있을 때 | |
| 빈 시간 칸 | 근무 시간 안에서 30분 간격으로 시작, 칸 길이 = 1회 수업 시간 | 칸 시작 간격 미정 |
| 신청 대기 처리 | 트레이너는 수락·거절, 수강생은 철회 가능 | |
| 다른 시간 제안 무응답 | 트레이너가 고르지 않으면 원래 시간으로 수업 시작에 자동 확정 | 4.4 그대로 |
| 변경 요청 개수 | 예약당 하나. 상대방 요청이 있으면 먼저 응답해야 하고, 같은 사람이 다시 보내면 이전 요청은 닫힘 | |
| 변경 요청 가능 상태 | 예약 확정만 (취소 요청 중이면 불가). 확정 대기는 트레이너가 바로 고치거나 수강생이 다른 시간 제안 | 4.4·4.6 |
| 수강생 취소 요청 | 예약 확정에서만. 확정 대기는 "거절"로 처리. 취소 요청을 보내면 열린 변경 요청은 닫힘 | |
| 트레이너 취소 가능 상태 | 확정 대기·확정·잔여 부족 (완료 승인 대기는 M4의 24시간 창) | |
| 잔여 부족 대상 | 앞으로의 신청 대기·확정 대기·확정 예약만 (이미 끝난 완료 승인 대기는 제외) | |
| 캘린더 표시 | 거절됨·만료는 숨기고, 취소는 회색으로 표시. 드래그는 시간 이동만(길이 변경 불가) | |

### M4 수업 완료 승인

| 영역 | 가정 | 근거·비고 |
| --- | --- | --- |
| 완료 차감 | 완료는 규칙 동의와 관계없이 1회 차감. 동의 여부는 노쇼·당일 취소 차감과 미승인 자동 완료에만 영향 | 3.5 |
| 노쇼 처리 시각 | 예약 확정은 수업 시작 + 규칙의 판정 시간(10·15·30분)이 지난 뒤, 완료 승인 대기는 종료 후 24시간 안 | 3.5, 5.1 |
| 수업 종료 처리 | 취소 요청이 없는 예약 확정만 종료 시각에 완료 승인 대기로 (취소 요청 중인 예약은 시작 시각에 이미 자동 취소) | |
| 승인 요청자 | 진행 트레이너(`approvalRequestedBy`) | 5.1 "요청한 트레이너" |
| PIN 오류 횟수 | 승인 실패와 별개로 저장 (실패해도 횟수는 남음). 5회면 본인인증으로 재설정할 때까지 잠김 | |
| 미가입 수강생 | PIN 승인 불가. 카톡 링크에서 가입 후 승인(M5). 미동의라 기한 뒤 "트레이너 확정" | 5.1 |
| 트레이너 확정 | 미동의 수강생의 미승인 기한이 지난 뒤에만 가능 | 5.1 |
| 완료 거절 → 수강생 의견 수락 | 수업을 인정하지 않고 차감 없이 취소 | 5.2 "차감 취소 또는 상태 변경" |
| 완료 거절 → 기존 처리 유지 | 완료(승인 방법: 이견 처리), 1회 차감 | |
| 노쇼 이의 → 수강생 의견 수락 | 취소로 바꾸고 차감했으면 되돌림(잔여 부족 예약 복구 포함) | |
| 이견 중 처리 | 이견이 있는 완료 승인 대기는 PIN 승인·자동 완료하지 않고 이견 처리로만 끝냄. 이견 처리 결과는 24시간 창과 관계없이 적용 | |
| 이의 제기 기한 | 따로 두지 않음 (한 수업에 한 번) | 명세에 없음 |
| 차감할 이용권이 없을 때 | 완료로 바꾸되 차감 없음(`NO_PASS`) 기록 | 이용권 기간 밖의 지난 수업 등 |
