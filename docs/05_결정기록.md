### M2 수강생·이용권·규칙

| 영역 | 가정 | 근거·비고 |
| --- | --- | --- |
| 예약 가능 횟수 계산 (3.4) | 예정 예약을 수업이 이른 순서로, 그 날짜에 유효한 이용권 중 "이전 이용권부터"(시작일 → 등록 순) 하나씩 배정. 예약 가능 횟수 = 그 날짜에 유효한 이용권들의 (잔여 − 배정된 예정 예약) 합 | "유효한 이용권 잔여 합 − 예정 예약 수"를 이용권이 여러 개일 때도 맞게 계산 |
| 잔여 부족 대상 | 어느 이용권에도 배정되지 못한 예정 예약. 이미 잔여 부족인 예약은 다른 예정 예약 뒤에 배정해, 자리가 생기면 복구 | 3.4 "가장 나중 예약", "이용권 추가 시 복구" |

| 환불·사용 중지 이용권 | 예약 가능 횟수에서 뺀다 | |
| 수강생 목록 상태 | 수강 중 = 오늘 쓸 수 있는 이용권(잔여 > 0) 있음 / 만료 = 없음(이용권 없음 포함) / 중단 = 수강 종료. "담당 없음"은 센터 화면(M7)에서 사용 | 트레이너 목록에는 담당 없는 수강생이 없음 |
| 규칙 미동의 표시 | 만료되지 않은 이용권 중 최신 규칙에 동의하지 않은 것이 있으면 | |

| 수강생별 규칙 | 기본 규칙과 다르게 고치면 이용권 전용 규칙(새 버전)을 만듦. 같으면 기본 규칙 버전을 그대로 씀 | |
| 기본 규칙 변경 | 이미 등록한 이용권에는 적용하지 않음(새로 등록하는 이용권부터) | 동의한 규칙을 몰래 바꾸지 않기 위해 |
